# Sanapeli

## In English

Sanapeli is a word game written in Python. The goal is to guess the right word based on clues. You can customize the word list and clues for different types of vocabulary, making it suitable for learning or fun.

## Suomeksi

Sanapeli on Pythonilla kirjoitettu sanapeli. Tavoitteena on arvata oikea sana vihjeiden perusteella. Voit muokata sanalistaa ja vihjeitä erilaisille sanastoille, mikä tekee pelistä sopivan oppimiseen tai hauskanpitoon.

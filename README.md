# Sanapeli

## In English

Sanapeli
========
A simple word game written in Python.

How to play
-----------
1. Run `main.py`.
2. The game randomly selects a word from the list in `words.txt`.
3. You will see a hint related to the word.
4. Try to guess the word based on the hint.

Custom word list
----------------
You can change the words and hints in `words.txt`. Use the format:

    word:hint

Each word and its hint should be on a separate line.

Requirements
------------
- Python 3

## Suomeksi

Sanapeli
========
Yksinkertainen sanapeli, joka on kirjoitettu Pythonilla.

Kuinka pelata
-------------
1. Käynnistä `main.py`.
2. Peli arpoo satunnaisesti sanan tiedostosta `words.txt`.
3. Näet vihjeen, joka liittyy kyseiseen sanaan.
4. Yritä arvata sana vihjeen perusteella.

Mukautettu sanalista
-------------------
Voit vaihtaa sanoja ja vihjeitä tiedostossa `words.txt`. Käytä muotoa:

    sana:vihje

Jokainen sana ja sen vihje tulee olla omalla rivillään.

Vaatimukset
-----------
- Python 3
